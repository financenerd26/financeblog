Privacy Policy

Last updated: April 2026

Summary

Finance Nerd does not collect, store, or transmit any personal or financial data. Your data never leaves your browser. There are no user accounts, no cookies, and no cross-site tracking. We use Cloudflare Web Analytics for anonymous, cookie-free page view statistics.

Data Storage

All data you enter into the tracker is stored exclusively in a JSONfile on your computer. On Chrome and Edge, the tracker can auto-save directly to a local file using the browser's File System Access API. On other browsers, you download the file manually.

The only piece of information stored in your browser's local storage is the filename of your last-opened tracker file, so the app can display it on the welcome screen. This can be cleared by clearing your browser data.

Analytics

This site uses Cloudflare Web Analytics, a privacy-focused analytics service. Here is exactly what it collects:

  • Pages visited and number of page views
  • Referring website (e.g. Google, Reddit, or a direct visit)
  • Country and general region (derived from your IP, but your IP is not stored)
  • Browser and device type (e.g. Chrome on Windows, Safari on iPhone)
  • Core Web Vitals (page load performance)

Here is what Cloudflare Web Analytics does not do:

  • Does not set any cookies
  • Does not collect or store your IP address
  • Does not track you across sites
  • Does not use fingerprinting
  • Does not collect any personal information
  • Does not have access to anything you type into the tools or calculators

We also use Google Search Console to understand how the site appears in search results. Search Console data is provided by Google based on search queries and does not involve any tracking code on this site.

No Cookies

This site does not set any cookies. Cloudflare Web Analytics is cookie-free by design. There are no first-party cookies, no third-party cookies, and no cookie consent banners because none are needed.

Third-Party Services

When you use the "Refresh Prices" feature in the investment tracker, market price data is fetched from Yahoo Finance through third-party CORS proxy services (corsproxy.io and allorigins.win). This means:

  • The ticker symbols you look up are sent to these proxy services
  • No personal or financial data (balances, holdings, etc.) is sent
  • Requests go directly from your browser; nothing passes through our servers
  • These proxies may log requests according to their own privacy policies

If you prefer not to use this feature, you can enter prices manually instead.
